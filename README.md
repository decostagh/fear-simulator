# Fear Ecology Simulator

授業用の2次元グリッド型シミュレーターです。

- 生体の恐怖値: 0〜10
- 捕食者からの逃走
- 採餌・餓死
- 捕食者の探索・追跡
- 寿命・老衰
- 恐怖値に応じた平常時の探索範囲
- 恐怖値ごとの繁殖回数・死亡回数・死因構成の可視化

`index.html` 単体で動作します。

> 教材用の概念実証モデルであり、実在生物の進化を定量的に再現することを目的としたものではありません。

## 制作

この教材用シミュレーターは、授業設計・モデル仕様・挙動の検討をユーザーが行い、実装・修正・ドキュメント整理を **ChatGPT（OpenAI）との対話を通じて共同制作**したものです。

ChatGPTはコード生成、実装補助、可視化調整、変更履歴の整理を担当しています。モデルの教育目的、採用するルール、解釈、各バージョンの採否はユーザー側で判断しています。
